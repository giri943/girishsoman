About

I care about the systems nobody notices, because they never break.

Most of my work lives in the layer between a product promise and the infrastructure that has to keep it. Queues that retry properly, indexes that hold under load, alerts that fire before a customer notices.

How I work

I start from failure modes rather than happy paths. That means instrumenting first, designing for retries and backpressure, and treating observability as a feature rather than an afterthought. Most of my recent work has been turning invisible backend behaviour into something a team can actually see and act on.

Strapi plugins I build and maintain

Each one started as a problem I kept solving on client Strapi 5 projects. Now they're packaged so nobody has to solve them again: TypeScript, tested, MIT-licensed and published on npm.

Tap for full screen

CSV Import & Export

strapi-plugin-csv-import-export npm

Bulk CSV import and export for Strapi 5, driven by your own schema. Editors get a template that matches the content type, a dry run that writes nothing, and a per-row report of exactly what went wrong, so a 4,000-row spreadsheet goes in without anyone writing a one-off script.

$ npm i strapi-plugin-csv-import-export
npm Source
  • Templates generated from the schema, so columns stay right as fields change
  • Dry-run validation with a downloadable per-row error report
  • Relations shown by label, not by document ID
  • Per-role permissions that start closed; streams 200,000-row files

Media WebP Converter & Upload Guard

strapi-plugin-media-webp-convertor npm

Converts uploads to WebP before they reach storage and refuses files a media library should never accept. Strapi checks neither on its own. Also bulk-converts an existing library and migrates media from local disk to S3.

$ npm i strapi-plugin-media-webp-convertor
npm Source
  • JPEG, PNG, GIF, BMP, TIFF and HEIC become WebP automatically
  • Magic-byte type checks: content must match the extension it claims
  • Blocks executables, image/PHP polyglots, scripted SVGs and PDFs with JavaScript
  • Bulk conversion with a savings report; local → S3 migration

Azure Blob Storage Provider

strapi-provider-upload-azure-blob npm

A Strapi 5 upload provider for Azure Blob Storage that covers the setups real deployments use: private containers, managed identities and a CDN in front, not just an account key and a public bucket.

$ npm i strapi-provider-upload-azure-blob
npm Source
  • Every Azure auth method, from account key and SAS to managed and workload identity
  • Private containers served through short-lived, read-only signed URLs
  • Azure CDN and Front Door hosts, with or without the container in the path
  • Stream uploads, so plugins that re-upload files (like the WebP converter) just work
